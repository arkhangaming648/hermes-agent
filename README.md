# Hermes Agent Web App

A simple, modern web application built with Hermes Agent and auto-deployed on Vercel.

## Features

- ✨ Modern dark-themed UI
- 🚀 Auto-deployment with Vercel
- 📱 Responsive design
- ⚡ Fast loading

## Vercel Auto-Deploy Setup

This project is configured for automatic deployment on Vercel.

### Deployment Steps

1. Push any changes to the `main` branch
2. Vercel automatically builds and deploys
3. Your site is live at: `https://hermes-agent.vercel.app`

## Local Development

```bash
# Using a simple HTTP server
npx serve .

# Or with Python
python -m http.server 8000
```
